## ▶️ Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/fbmcarmo/portfolio.git
```

Entre na pasta:

```bash
cd portfolio
```

Instale as dependências:

```bash
npm install
```

Execute o servidor de desenvolvimento:

```bash
npm run dev
```

A aplicação estará disponível em:

```text
http://localhost:3000
```

---

## 📦 Build para Produção

```bash
npm run build
```

Para iniciar a versão de produção:

```bash
npm start
```
